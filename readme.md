## Project Overview

Kwa Olga Car Wash & Leisure Lounge is a website development project created to provide customers with information about the business, its services, food, drinks, cocktails, events, bookings and location.

The website combines professional car wash services with food, drinks and a leisure lounge experience.

The website is being developed using HTML in Visual Studio Code as part of Part 1 of the project.

---

## Website Goals and Objectives

The main goals of the Kwa Olga website are to:

- Create an online presence for Kwa Olga.
- Provide information about the business.
- Display available car wash services.
- Display the food and drinks menu.
- Display cocktails and beverages.
- Provide information about specials and events.
- Display photographs of Kwa Olga.
- Allow customers to make bookings.
- Provide contact information.
- Provide the location of Kwa Olga.
- Create a clear and functional navigation system.
- Create a professional and user-friendly website.

---

## Target Audience

The website is aimed at:

- Local customers.
- Car owners.
- Customers looking for car wash services.
- Customers interested in food and drinks.
- Customers looking for a place to relax.
- Customers interested in cocktails.
- Customers booking tables.
- Customers planning birthdays and functions.
- Customers interested in Kwa Olga events and specials.
